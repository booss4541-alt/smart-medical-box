# Smart Medical Box 💊 – Open-Source Healthcare Technology

Affordable, intelligent medication-adherence system combining embedded systems, IoT, sensors, and AI.

> Helping elderly patients, chronic-disease patients, caregivers, and clinicians reduce missed doses.

## 🎯 Problem
Medication non-adherence causes preventable hospitalizations, especially for elderly and chronic patients. Commercial smart pillboxes are expensive and closed-source.

## ✨ What makes it different?
- Medication reminders (sound / light / app)
- Sensor-based monitoring (lid / compartment detection)
- Remote notifications for caregivers
- Accessibility-first design (large UI, audio prompts)
- Adherence tracking + open data format
- Affordable BOM for students & clinics to reproduce

## 🛠️ Tech (planned)
- ESP32 + sensors, MQTT, mobile app, REST API, AI reminders
- See `docs/` for research notes and methodology
